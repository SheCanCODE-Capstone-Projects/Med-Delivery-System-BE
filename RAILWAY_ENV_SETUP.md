# Railway Environment Variables - Quick Setup

## 🚨 CRITICAL: Email Configuration (MISSING - CAUSING EMAIL FAILURE)

```bash
MAIL_USERNAME=your-email@gmail.com
MAIL_PASSWORD=your-16-char-app-password
```

### How to Get Gmail App Password:
1. Enable 2-Step Verification: https://myaccount.google.com/security
2. Generate App Password: https://myaccount.google.com/apppasswords
3. Select "Mail" → "Other (Custom name)" → Generate
4. Copy 16-character password (remove spaces)
5. Paste into Railway as `MAIL_PASSWORD`

## Complete Environment Variables List

### Database (PostgreSQL)
```bash
PGHOST=postgres.railway.internal
PGPORT=5432
PGDATABASE=railway
PGUSER=postgres
PGPASSWORD=<auto-generated-by-railway>
```

### Cache (Redis)
```bash
REDISHOST=redis.railway.internal
REDISPORT=6379
REDISPASSWORD=<leave-empty-or-set-password>
```

### Security (JWT)
```bash
JWT_SECRET=<generate-random-64-char-string>
```

### Email (Gmail SMTP) ⚠️ REQUIRED FOR OTP
```bash
MAIL_USERNAME=your-email@gmail.com
MAIL_PASSWORD=<gmail-app-password-16-chars>
```

### OAuth2 (Google Login)
```bash
GOOGLE_CLIENT_ID=<your-google-client-id>
GOOGLE_CLIENT_SECRET=<your-google-client-secret>
OAUTH2_REDIRECT_URI=https://your-app.railway.app/login/oauth2/code/google
```

### CORS & WebSocket
```bash
CORS_ALLOWED_ORIGINS=https://your-frontend.com,https://another-domain.com
WEBSOCKET_ALLOWED_ORIGINS=https://your-frontend.com,https://another-domain.com
```

### Firebase (Optional - for phone OTP)
```bash
FIREBASE_SERVICE_ACCOUNT=<base64-encoded-json-or-json-string>
```

### AI Features (Optional)
```bash
OPENAI_API_KEY=<your-openai-api-key>
```

## Quick Commands

### Generate JWT Secret (64 characters)
```bash
openssl rand -base64 48
```

### Check Railway Logs
```bash
railway logs
```

### Set Variable in Railway CLI
```bash
railway variables set MAIL_USERNAME=your-email@gmail.com
railway variables set MAIL_PASSWORD=your-app-password
```

### Set Variable in Railway Dashboard
1. Go to your project
2. Click "Variables" tab
3. Click "New Variable"
4. Enter name and value
5. Click "Add"

## Troubleshooting

| Error | Solution |
|-------|----------|
| `MAIL_USERNAME env: NOT SET` | Add `MAIL_USERNAME` to Railway variables |
| `MAIL_PASSWORD env: NOT SET` | Add `MAIL_PASSWORD` to Railway variables |
| `Authentication failed` | Use App Password, not regular Gmail password |
| `Connection refused` | Check port 587 is allowed, try port 465 |
| `SMTP connection test FAILED` | Verify credentials, regenerate App Password |
